## 🛡️ DRyhon Security Audit

> **Windows Security Auditing Framework**

A PowerShell-based framework designed to automate Windows security assessments, identify common security weaknesses, and provide actionable hardening recommendations.

### Highlights

- Windows Security Auditing
- Security Policy Analysis
- User & Privilege Enumeration
- Service & Process Inspection
- Scheduled Task Review
- Windows Defender Analysis
- Firewall Assessment
- Reporting & Recommendations

**Status:** ✅ Active Development

---

## 🌐 ReconTool

> **Reconnaissance & Information Gathering Toolkit**

A reconnaissance toolkit that streamlines information gathering and target enumeration for web application security assessments.

### Highlights

- DNS Enumeration
- WHOIS Lookup
- Subdomain Discovery
- Technology Fingerprinting
- HTTP Header Analysis
- robots.txt Analysis
- Security Header Inspection
- Sensitive File Discovery

**Status:** 🚧 In Development

---

## 📡 PingSweeper

> **Network Host Discovery Utility**

A lightweight host discovery tool built for identifying active hosts across local and remote networks.

### Highlights

- ICMP Host Discovery
- Fast Network Scanning
- Reachability Testing
- Lightweight & Cross Platform
- Simple Reporting

**Status:** ✅ Active
